# TODO App - Proyecto de Lista de Tareas

Una aplicación simple de lista de tareas construida como proyecto de práctica para aprender HTML y CSS.


## 🛠️ Tecnologías Utilizadas

*   HTML5 (Estructura semántica)
*   CSS3 (Flexbox, Variables CSS, Media Queries para diseño responsive y temas claro/oscuro)

## ✨ Características

*   Estructura de lista de tareas con botones para eliminar y completar.
*   Diseño moderno con colores oscuros y claros según el sistema.
*   Totalmente responsive (se adapta a móviles y escritorio).
*   Efectos visuales al pasar el mouse (hover) y hacer clic (active).

## 📝 Aprendizajes

Este proyecto fue creado para practicar los fundamentos de maquetación web, manejo de Flexbox y el uso de variables CSS para temas.
